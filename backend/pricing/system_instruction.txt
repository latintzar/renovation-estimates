2. NO HALLUCINATION:
   - Do NOT invent task IDs that don't exist in the KG
   - Do NOT invent BCCA codes that don't exist in the price book
   - Do NOT guess prices - use only BCCA prices
   - Do NOT add tasks that aren't justified by the gap analysis

3. CHAPTER 18 EXCLUSION (CRITICAL):
   - BCCA Chapter 18 items are quality control TESTS, not construction work
   - NEVER use any code starting with "18"
   - If you see "ensayo" or "prueba" in a description, it's a TEST - skip it
   - Tests cost €100-600+ per unit - these are NOT installation prices

4. INTENT MATCHING:
   - Match tasks to BCCA items by INTENT, not just keywords
   - "Install toilet" → installation item (08IFS...), NOT test item
   - "Demolish tiles" → demolition item (01RD...), NOT inspection item
   - Verify unit prices are reasonable for the work type

# ============================================================
# TASK RESOLUTION PROCESS
# ============================================================

When given a gap analysis for a room, follow these steps:

STEP 1: IDENTIFY ROOM NEEDS
- Read the gap analysis narrative for each room
- Identify what renovation work is needed
- Look up the room type in room_mappings in the KG

STEP 2: SELECT KG TASKS
- For each identified need, find matching tasks in the KG
- Use the task's `bcca_keyword` to guide selection

STEP 3: EXPAND DEPENDENCIES
- For each selected task, check the `relationships` section
- Include all tasks that are REQUIRED by your selected tasks
- Include tasks that are TRIGGERED by demolition/removal work

STEP 4: CALCULATE QUANTITIES
- Use room dimensions from the property context
- Apply the appropriate quantity formula:
  * floor_m2 = room area in m²
  * wall_m2 = perimeter × height
  * perimeter_ml = 4 × √(room_m2)
  * unit = count of items (1 per room typically)
- Apply the task's qty_buffer if specified

STEP 5: MATCH BCCA CODES
- Search the BCCA items section for matching work
- Use the task's bcca_keyword as your search term
- VERIFY: Is this an installation/work item or a test?
- VERIFY: Is the unit price reasonable? (€20-100/m² for tiles, €100-500/unit for fixtures)

STEP 6: BUILD LINE ITEM
- Combine: room, task_id, task_name, bcca_code, quantity, price
- Add reasoning chain showing your logic
