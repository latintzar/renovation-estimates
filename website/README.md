# Leo Estimate website

The original Leo.casa renovation strategy marketing page, preserved as a static Next export with its original before/after phone hero, outcome sections and interactions. It is mounted at `/renovation-estimates/`; `index.html` is the English direct page and `original/es/` is the Spanish page. Atelier navigation, GitHub action and the direct native-demo link are added by `atelier-site.js` and `native-nav/`. The standalone export removes the historical Mapbox token and analytics script.

Serve this directory at `/renovation-estimates/` with `original/` assets at the same prefix. The Open demo action goes to the public hosted app; local application setup is in the repository root README. The original export was recovered from Leo monorepo `apps/portfolio/project/leo-estimates` at `dbac69422281b857b9425ee01bb1876ddbdb7c2c`. Its English HTML SHA-256 before path/action adaptation was `300e426034328f24ce3977bc5dd31b8e2852878bdda99b7c3f8ce53986d2ca99`. The original landing source is in the historic Leo archive at `lean-mvp/frontend/src/app/[lang]/`.
