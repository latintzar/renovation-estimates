I BCCA Match
Match work items to BCCA catalog entries. Denylist filters commercial/institutional codes; Flash Lite LLM reranks top-10 embedding candidates for physical correctness.

J Quant Plan (signals)
Choose the ONE measurable room signal per work item (schema-first, room-physical)

output: v4_quant_plan_{strategy}_{dimension}
K Forage (measure signals)
Measure signals from room photos, anchored to Smart M² room dimensions. Then run a Pro zero-rescue pass so no work item prices at 0.

output: v4_signals_{strategy}
L BOQ (Bill of Quantities)

guards: denylist filter + qty caps + listing_sqm anchor
output: boq_line_items
