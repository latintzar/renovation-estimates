# Interface captures
Actual Estimate components in the reviewed portable source derivative, based on
leo-archive commit 4dca5f9b. Captured at 1600×1000 and 390×844, DPR 1.

The listing workspace receives an empty local API fixture. The paste modal contains
an authored example.invalid URL; import remains unsubmitted. The first-result
report uses the real synthetic costing receipt. Its historical extra percentage
arithmetic remains part of the native report component.

capture-interface.py starts its own loopback production server, provides only
explicit synthetic API responses, blocks foreign browser requests, waits for native
control readiness and records source/font/PNG hashes in proof.json. It changes no
product CSS, labels or component geometry. Reproduction requires the frontend build
and Playwright 1.58.0 with its bundled Chromium.

These are interface verification captures, rather than proof of live model,
listing acquisition, comparable data or a commissioned recipient account.
