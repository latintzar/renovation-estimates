# Third-party notices
Original source is MIT, copyright Peter Neyra.

Playfair Display and Source Sans3 retain SIL Open Font License 1.1. Exact font bytes,
upstream blob IDs and hashes are recorded in frontend/public/fonts/provenance.json.
The two complete OFL permission/copyright notices sit beside the font files.

Dependency versions and licence identifiers are inventoried in
[dependency-licenses.json](docs/dependency-licenses.json). npm installs each package's
own distribution and notices from the locked registry URLs. Python dependencies
similarly retain the licences in their installed distributions. Their code is installed
by the recipient, rather than copied into this source tree.

Construction/reference data, third-party document distributions and property media
are outside this export. [Data rights](docs/providers.md#data-rights).

The retained UI primitives follow shadcn/ui’s component pattern. Its complete MIT notice is preserved at [third_party/shadcn-ui-LICENSE.txt](third_party/shadcn-ui-LICENSE.txt), with an exact upstream blob receipt.
